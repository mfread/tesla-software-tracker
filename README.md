# tesla-branch-tree
* Display a tree or table view of Tesla software end-points.
* Highlights the ones pertinent to the car selected if chosen to do so.
* Data comes from various apps, including Teslascope, Tessie, Not A Tesla, Teslafi, and X.
* Not all country info is captured (as this would slow down the process and UI). Countries included in the nightly data refresh are:
  AU - Australia
  BE - Belgium
  CA - Canada
  DK - Denmark
  GB - Great Britain
  KR - Korea (South)
  MX - Mexico
  NL - Netherlands
  NZ - New Zealand
  US - USA
* snapshot.json updated 5am Australian Eastern Standard Time.
